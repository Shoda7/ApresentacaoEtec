# Do Caderno ao Big Data

Apresentação sobre bancos de dados para o curso de Informática da ETEC, feita como um site que funciona como slides, com animações e partes interativas.

A aula segue a história do **CantinaApp**: o caderno da tia da cantina vira um app, que cresce até atender o Brasil inteiro. Em cada etapa, algo quebra e um conceito novo aparece (índices, B-Tree, ACID, réplicas, NoSQL, particionamento e mais).

## Como abrir

Basta abrir o `index.html` no navegador. Não precisa de internet, instalação ou build.

## Teclas

| Tecla | Ação |
|---|---|
| → / espaço / clique | Avança |
| ← / clique direito | Volta |
| `O` | Visão geral dos slides |
| `N` | Notas de quem apresenta |
| `T` | Inicia o cronômetro |
| `C` | Troca os nomes da tia e da cantina |
| `F` | Tela cheia |
| `B` | Tela preta |

## Estrutura

- `index.html`: slides e notas
- `css/`: estilos
- `js/`: navegação e animações
- `fonts/` e `img/`: fontes e imagens locais
- `conteudo-aula.md`: roteiro completo da aula
